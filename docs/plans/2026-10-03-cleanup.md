> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Take the Workers and broker layout off `main` so `apps/api` is the Sydney service's home and CI no longer builds a Worker or a broker image.

**Architecture:** Six commits, each leaving CI green. Crypto leaves the Workers pool first. The gateway, residency package, and Worker checkers go next, while `apps/api` still has its Wrangler files, because `kms-broker-binding` and `residency-cell` still run until that commit. Living docs flip last, and the roadmap is the last commit.

**Tech Stack:** TypeScript, Vitest on Node, Terraform 1.11.4, pnpm, GitHub Actions. No cloud apply.
