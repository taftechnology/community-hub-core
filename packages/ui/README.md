# @community-hub/ui

Shared web UI primitives copied from shadcn/ui (`base-nova`).

Add or refresh components with the pinned CLI (`shadcn@4.21.0`):

```bash
pnpm --filter @community-hub/ui shadcn add button
```

Generate `theme.css` from `@community-hub/tokens`:

```bash
pnpm --filter @community-hub/ui generate
```
